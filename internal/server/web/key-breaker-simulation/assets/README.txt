Quentra Key Breaker — brand assets
===================================

Drop the provided brand PNGs into THIS folder using these exact file names.
The simulation auto-detects them at load; until then it renders a vector
fallback (silhouette hero + vector Quentra mark), so the demo always works.

  key-breaker.png            <- Key Breaker character (hero, transparent PNG)
  quentra-icon.png           <- Quentra logo icon (the "Q" mark)
  quentra-logo.png           <- Quentra wordmark (full logo)
  key-breaker-reference.png  <- reference composition (optional, not drawn)

Notes
- No image is required for the demo to run.
- File names must match exactly (lowercase, hyphenated) — see js/config.js ASSETS.
- Nothing here is sent anywhere; assets are loaded locally by the browser only.
